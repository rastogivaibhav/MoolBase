# EGPM06 predeclared development protocol
Observed EGPM05 invalid IDs included bracket-only IDs and IDs followed by text; normalize only one surrounding bracket pair, reject any suffix/unknown ID. Stable source IDs use document ID and exact offsets, not retrieval rank. Windows preserve literal text and hash; no synthesized source text. Model selects enum IDs and is asked one stage and subject at a time; stage is caller-owned. Alias merging requires exact normalization or independent NLI identity support with both entities present. Native graph adjacency is traversed for each prefix, Python parity required. Static C/D use same initial retrieval budgets (10); active C/D may fetch up to 3 additional docs per missing continuation, maximum 16 total, frontier 3, max 10 evidence windows per extraction. Matched-text control gets exactly the final retrieved documents; graph construction costs are not matched, report wall time and document counts. Same question-only plan and oracle graph extraction after ordinary arms; no gold labels/decomposition in non-oracle inference. Independent NLI .8 threshold unchanged from EGPM05. The question-conditioned graph is experimental adapter logic, not native core reasoning; graph state is re-materialized for each native snapshot query. No claim of database-specific accuracy versus identical Python graph algorithm. Eight questions are development fixtures, NOT held-out validation; do not tune on these then present as final benchmark. Gate: all integration contracts pass, no malformed or forged citations accepted, record accepted edges and actual full paths, report exact/F1, abstention, oracle graph and matched-text comparisons. If gate fails report failure, do not scale. Future 100-question held-out stratified sample, same full 1000 corpus and pinned models, original judge separately, paired bootstrap; no post hoc threshold adjustment. Gold support paragraphs may not entail benchmark phrasing (e.g. UHF financing vs distribution); classify as benchmark/evidence discrepancy, not force support. Model-generated facts remain independently checked but NLI imperfect.
