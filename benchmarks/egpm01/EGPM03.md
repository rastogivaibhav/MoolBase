# EGPM-03
Full exact-MiniLM vs native Flat parity benchmark with the complete author manifest, pinned encoder and shared corpus. QA smoke uses 3B executive and 1.5B released memory, BF16 CPU, original structured inference functions and prompts, bounded 2+2 turns with greedy capped decoding. It is not the exact paper settings or judge. Closed-book and oracle controls isolate executive skill; C/D have matched verifier-only and native gate controls. The semantic verifier is a separate call to the same executive, not an independent model. Candidate cites must be verbatim in retrieved passages. Native gate is a conservative single-chain proof-of-integration using a binary showcase, not a complete knowledge graph. Errors, abstentions and strict exact-match/token-F1 are retained. No gold labels in non-oracle prompts. Four questions are an engineering smoke, not a statistical comparison.
