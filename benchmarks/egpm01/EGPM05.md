# EGPM-05 native evidence graph
Eight-question CPU pilot on the same 120-source-row corpus as EGPM04, but 10 documents per arm rather than 5. Shared plan from question only; sentence IDs with exact offsets/hash, endpoint mention checks, independently verified relation triples using cross-encoder/nli-deberta-v3-small, fixed .8 entailment/contradiction threshold. Neutral/unknown is not contradiction. No gold in inference except oracle. C baseline retrieved docs and D MeMo expanded retrieved docs; matched text controls and Python graph reference. C++ adapter traverses real MoolBase persisted directed adjacency using snapshot, stage order and explicit signed evidence; graph decision policy is research adapter code, not an existing native core epistemic capability. The single-chain native epistemic gate is a separate arm with no artificial independent-family inflation. Contradicted chain does not logically refute endpoint; missing, ambiguous, contested and refuted-chain outcomes are reported. Synthetic fixture checks are integration tests, not semantic accuracy. Limitations: question-conditioned graph, exact lexical entity joining, independent NLI may be wrong, small sample and no original judge; no claim of superiority.
