MoolBase

Persistent evidence and inspectable reasoning for agents.

Docker Desktop quickstart — developer evaluation, not GA.

1. Start the native engine

Download the source, then run these commands in its root directory:

docker compose up -d --build
docker compose ps
docker compose logs moolbase

This extension is a documentation and discovery tab; it does not install, run or control the database automatically.

2. Verify the engine

The local server uses 127.0.0.1:8080 and persists evidence in the Docker volume moolbase-data. Verify the healthy status with docker inspect and exercise a documented API route before relying on results.

3. Explore the evidence

Open Evidence Lab · Source and API documentation

Scores represent policy strengths, not calibrated probabilities. The research interface and this extension are distinct from the local native server.
