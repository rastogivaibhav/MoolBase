PRIVACY NOTICE — DEVELOPER ALPHA

Uploads are private, temporary and never published automatically

This notice is a release template. The operator must replace the contact and hosting placeholders before public publication.

What is processed

Uploaded structured datasets, their filenames, a normalised evidence graph, run configuration, execution results, checksums, technical logs and anonymous session identifiers.

Why

To validate the upload, execute a bounded GrapheneDB experiment, return an inspectable result and create a reproducibility bundle.

Retention

Anonymous upload and run artifacts are scheduled for deletion within 60 minutes. Selecting “Delete my session” requests immediate deletion.

Publication

Raw uploads, filenames, graph content and run results are not publicly listed. Any future anonymised publication flow must require a separate explicit consent step.

Prohibited data

Do not upload personal, confidential, medical, financial, credential-bearing, export-controlled or unauthorised third-party data.

Security screening

Uploads may be checked for unsafe archives, credential patterns and malware before parsing. Rejected files are not executed.
