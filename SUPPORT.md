# Support

MoolBase is currently a released developer preview for evaluation and controlled pilots. Support is community- and maintainer-driven rather than covered by a commercial SLA.

## I am trying MoolBase for the first time

Start with:

1. [README](README.md)
2. [Developer quickstart](docs/DEVELOPER_QUICKSTART.md)
3. [Independent reproduction guide](docs/INDEPENDENT_REPRODUCTION.md)

If the documented path fails, open a GitHub issue and include your operating system, compiler, CMake/Python versions, the exact commit tested and the relevant command output.

## I found a reproducibility problem or counterexample

Use the **Independent reproduction report** issue template. Failed reproductions, null results and adversarial cases are useful project evidence.

## I found a bug

Use the **Bug report** template and provide the smallest reproducible case you can.

## I have a feature or integration proposal

Use the **Feature / integration proposal** template. Explain the developer problem first; implementation ideas are welcome but optional.

## Security issues

Do **not** report vulnerabilities or sensitive security information in a public issue. Follow [SECURITY.md](SECURITY.md).

## What this support channel is not

Please do not post credentials, API keys, proprietary customer data, confidential employer/client material or private personal information in issues or discussions.
