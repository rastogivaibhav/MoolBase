# TheHypoKosh Experimental Runtime v1

This implementation materialises the paper thesis as executable components rather than documentation-only claims.

## Runtime path

`Graphene expansion -> immutable FiberBundle -> StabilityCriticV0 -> CorrectiveEscape -> convergence -> opposition -> bounded re-expansion -> governed projection -> model-world event`

## Implemented contracts

- immutable, deterministic FiberBundle with exact duplicate elimination
- source-lineage-aware independent-path degeneracy
- temporal, diversity, degeneracy, provenance, contradiction, pattern-lock and missing-evidence stability metrics
- bounded corrective escape plans
- retained alternatives during convergence
- opposition and re-expansion through the existing dialectic engine
- governed statuses: resolved, provisionally resolved, contested, evidence required, abstain and speculative
- append-only checksummed model-world events
- no silent verification of hypothetical or inferred nodes
- deterministic reasoning receipts

## Non-claims

`StabilityCriticV0` is inspired by Lyapunov-style stability analysis but is not claimed to be a mathematically proven Lyapunov function. The current model world is a bounded runtime ledger and audit layer, not yet a distributed million-node autonomous scheduler.
