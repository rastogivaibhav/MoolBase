# MoolBase quickstart

The maintained first-run instructions are in [Developer quickstart](DEVELOPER_QUICKSTART.md). Use that guide for the released `v0.6.0-alpha.2` customer-memory example, platform prerequisites and CMake integration.

For integration contracts and persistence boundaries, read [Agent integration](AGENT_INTEGRATION.md). For precompiled Linux downloads, examples against the installed database and optional source, use the [Evidence Lab downloads](https://moolbase.rasvai.com) and its [installation instructions](https://moolbase.rasvai.com/INSTALL.md).

This page redirects readers to the canonical guide so that competing quickstarts do not drift.
